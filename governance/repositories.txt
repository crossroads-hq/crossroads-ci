# Format, one repository per line, whitespace-separated:
#
#   owner/repository  profile  branch
#
# profile is one of:
#   full       ruleset-full.json    — requires the "PR Validation" status check.
#                                     Only for repositories that HAVE a gate job
#                                     with that exact name: requiring a check
#                                     that never reports blocks every pull
#                                     request permanently, with no escape,
#                                     because bypass_actors is empty and
#                                     administrators are enforced.
#   full+tags  ruleset-full.json + tag-ruleset.json — as above, plus v* release
#                                     tags become immutable. For repositories
#                                     that publish from a tag push.
#   minimal    ruleset-minimal.json — pull-request-only merges, no force-push,
#                                     no deletion, but NO required status check.
#                                     For repositories with no CI. This profile
#                                     exists precisely so "no CI yet" stops
#                                     being a reason to have no protection at
#                                     all.
#
# Blank lines and comments are ignored.
